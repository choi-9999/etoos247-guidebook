# 🎓 이투스247학원 신규 직원 온보딩 교육 웹 포털

가맹점 신입 직원 집체/온라인 교육 시 두꺼운 실물 종이 가이드북 대신 사용하는 **디지털 가이드북 & 섹션별 자료실 웹페이지**입니다.

---

## 🚀 빠른 시작 방법

### 방법 1. 브라우저에서 바로 열기 (설치 불필요)
- 폴더 내 **`index.html`** 파일을 더블 클릭하면 Chrome, Edge, Safari 등 모든 브라우저에서 즉시 실행됩니다.
- 인터넷이나 별도 웹 서버 없이도 교재 본문, 표, 280여 개의 고해상도 스크린샷이 즉시 렌더링됩니다.

### 방법 2. 사내 로컬 웹 서버로 열기 (선택 사항)
```bash
npx serve .
# 또는 python -m http.server 8080
```

## ✨ 핵심 기능 안내

### 1. 📑 스마트 목차 & 직무별 필터
- **7대 표준 교육 챕터**:
  1. `1. 이투스247학원의 이해` (p.4)
  2. `2. 이투스247학원 시스템` (p.10) - 연간일정, 역할분담, 일과표
  3. `3. 신입생 모집 및 재원생 만족` (p.42) - 전화/방문상담 스크립트
  4. `4. 이투스247학원 재원생 정착 프로세스` (p.67) - LMTI/LMAT, 퇴원방지
  5. `5. 이투스247학원 LMS` (p.93) - MY247 APP, 스톱워치, 시간표
  6. `6. 이투스247학원 ERP 운영관리` (p.133) - 수납·환불, 출결단말기 오류해결
  7. `<부록> 이투스247학원 실무 양식` (p.188) - 상벌점표, 반성문, 상담일지 등
- **직무 필터**: `[전체]`, `[행정직원 필수]`, `[학습매니저 필수]` 버튼으로 본인 직무에 맞는 섹션만 빠르게 필터링 가능합니다.

### 2. 📂 섹션별 자료집 업로드 & 다운로드
- 각 챕터 상단 **[📎 섹션 자료집]** 탭에서 해당 섹션 전용 강의 PPT, 실무 양식, 체크리스트를 원클릭으로 다운로드할 수 있습니다.
- 우측 상단 **[⚙️ 관리자 모드]**에서 언제든 새 자료(PDF, PPT, Word, Excel, HWP 등)를 추가 등록하거나 삭제할 수 있습니다.

### 3. 🎯 강사 실시간 진도(Live Session) 동기화
- 집체 교육 중 강사가 관리자 모드에서 *"현재 2장 진행 중"*으로 지정하면, 모든 교육생 화면 상단에 핫배너가 노출되어 클릭 한 번으로 해당 섹션으로 모일 수 있습니다.

### 4. 🔍 통합 실시간 검색 & 형광펜
- 상단 검색창에 `"환불"`, `"벌점"`, `"출결 오류"`, `"비즈모아샷"` 등을 입력하면 해당 내용이 수록된 챕터와 본문 위치로 부드럽게 스크롤 및 하이라이트됩니다.

### 5. 🖍️ 나만의 실무 메모 (자동 저장)
- 각 챕터의 **[실무 메모]** 탭에 강사의 강조 사항이나 가맹점 특이사항을 적어두면 브라우저에 자동 보관됩니다.

### 6. ✅ 학습 진도율 체크
- 챕터 학습 후 **[학습 완료 체크]** 버튼을 누르면 상단 진도 게이지(0% ~ 100%)가 갱신됩니다.
